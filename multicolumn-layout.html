Purpose

This page demonstrates a multicolumn layout built with semantic HTML5 landmarks: header, nav, main, two aside elements, and footer. Styles live in an external stylesheet.

Grid and flexbox

The overall two-dimensional layout uses CSS Grid with named grid-template-areas. The navigation list uses Flexbox for one-dimensional alignment; on small screens the links stack vertically with larger touch targets for easier thumb navigation.

Responsive layout

A viewport meta tag and media queries reorder content for tablet and mobile widths. On tablet, the main column spans the full width with the asides side by side below. On mobile, regions stack in a single column.
